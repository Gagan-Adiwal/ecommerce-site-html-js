# 🛒 E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**.  
This project showcases a clean UI, smooth interactions, and essential features of a shopping platform.

---

## 🚀 Features
- 🖥️ Fully responsive design for all devices  
- 🛍️ Product listing with images, names, and prices  
- 🛒 Add to Cart & Remove from Cart functionality  
- 💰 Dynamic cart total calculation  
- 🎨 Clean and modern UI with custom CSS styling  
- ⚡ Lightweight, fast, and beginner-friendly  

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Interactivity and functionality  

## 🎯 Future Improvements

- 🔍 **Product search and filter**
- ❤️ **Wishlist feature**
- 👤 **User authentication (Login/Signup)**
- 💳 **Payment gateway integration**
